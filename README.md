# NovaPulse — SaaS Landing Page

A responsive front-end SaaS landing page built with semantic **HTML5**, **Tailwind CSS**, and **Vanilla JavaScript**.

## Folder Contents
* `index.html` — Complete landing page markup styled with Tailwind CSS utility classes.
* `script.js` — Interactive JavaScript for the mobile navigation menu, Monthly/Annual billing switcher, plan selection buttons, and demo request form validation.
* `README.md` — Setup instructions and overview of technologies used.
* `SUBMISSION_NOTES.txt` — Concise project explanation describing design decisions and technical solutions.

## How to Run Locally
1. Extract the `NovaPulse-Landing-Page` folder from the ZIP archive.
2. Double-click `index.html` to open it in any modern web browser.
3. Resize the browser window below `768px` (or open DevTools with `F12` and toggle mobile view) to test the responsive layout and mobile hamburger menu.
