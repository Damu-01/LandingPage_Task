Design Choices & Challenges Solved:
For this assignment, I designed a clean, high-contrast SaaS landing page for NovaPulse, a real-time customer analytics platform, using sky-blue and warm-orange accents over a neutral slate background to establish visual hierarchy and trust. I structured the page into scannable sections—including a sticky navigation bar, hero dashboard preview, three-column feature cards, a step-by-step onboarding guide, an interactive monthly/annual pricing switcher, and a validated demo request form. One key technical challenge was ensuring the mobile hamburger menu opened reliably across different browsers without Tailwind utility class specificity conflicts. I solved this by separating the mobile dropdown container from desktop-only flex utilities and toggling its display state directly via modular JavaScript handlers.
